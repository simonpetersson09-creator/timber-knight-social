# Mr.B. Chess

Mr.B. chess

Jag vill hugga ett schack. Kolla våra övriga appar för att hitta en röd tråd. 

Jag vill att schackbrädet ska vara i trä. Ena parten ska ha svart pjäser och andra parter ska ha teäpfjäser. 

Fixa det. Så har vi en utgångspunkt.

Man ska kunna bjud in vänner, lägga till vänner. Det ska finnas både onlinespel och spela mot dator.  Likt yatzy. 

Gör det riktigt snygg så användaren får en wow känsla
